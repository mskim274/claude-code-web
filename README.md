## 프로젝트 개요

### 무엇을 하는 프로그램인가요?

이 프로그램은 **주식 트레이딩 전략을 테스트하고 최적화하는 시스템**입니다.

**핵심 기능:**
1. 📊 **자동 데이터 수집**: 키움증권 API를 통해 실시간 주가 데이터 수집
2. 🔍 **백테스팅**: 과거 데이터로 트레이딩 전략 성과 검증
3. 🤖 **ML 전략**: 머신러닝 기반 매매 전략 (LightGBM + SHAP)
4. 📈 **시각화**: 백테스팅 결과를 차트와 그래프로 표시
5. 💾 **데이터 관리**: PostgreSQL 데이터베이스에 주가 데이터 저장

---

## 주요 기능

### 1. 데이터 수집 📊
- **종목 리스트**: KOSPI, KOSDAQ 전체 종목
- **일봉/분봉/틱 데이터**: 최대 10년 과거 데이터
- **자동 업데이트**: 예약 수집 가능

### 2. 백테스팅 전략 🔍
1. **이동평균 교차** - 골든크로스/데드크로스
2. **RSI 전략** - 과매도/과매수 구간 매매
3. **볼린저 밴드** - 밴드 돌파 전략
4. **ML 전략** - LightGBM 기반 예측

### 3. 기술적 지표 📈
- **TA-Lib 통합**: 150개 이상 지표 (MA, RSI, MACD, BB 등)
- **자동 계산**: 백테스팅 시 자동으로 지표 계산

## 빠른 시작 (5분 완성)

### 1. 프로그램 실행
```powershell
python gui_main.py
```

### 2. 백테스팅 해보기
1. **백테스트** 탭 클릭
2. 종목코드: `005930` (삼성전자)
3. 기간: 2024-01-01 ~ 2025-01-01
4. 전략: **이동평균 교차**
5. **백테스트 실행** 클릭!

## 설치 가이드

### 필수 요구사항
1. **Python 3.12 (64비트)** - 메인 애플리케이션
2. **Python 3.12 (32비트)** - 키움 API용 (C:\Python312-32)
3. **PostgreSQL** - 데이터 저장
4. **키움증권 계좌** - 모의투자 or 실계좌

### 설치 단계
```powershell
# 1. 64비트 패키지 설치
pip install -r requirements.txt

# 2. 32비트 패키지 설치
C:\Python312-32\python.exe -m pip install pyqt5 pywin32
C:\Python312-32\Scripts\pywin32_postinstall.exe -install

# 3. 데이터베이스 설정
# .env 파일 생성 후 DB 정보 입력

# 4. 실행
python gui_main.py
```

## 사용 방법

### 데이터 수집
1. **데이터 수집** 탭 클릭
2. **종목 리스트 수집** → 키움 로그인 → 완료 (1-2분)
3. **일봉 데이터 수집** → 기간 선택 → 완료 (2-3일)

### 백테스팅
1. **백테스트** 탭 클릭
2. 종목코드 입력 (예: 005930)
3. 기간 설정
4. 전략 선택
5. 파라미터 설정
6. **백테스트 실행** 클릭

**결과 확인:**
- 수익률, 거래 횟수, 승률, MDD
- 자산 곡선 차트
- 매수/매도 시점 표시

## 자주 묻는 질문 (FAQ)

**Q1: 실제 자동매매 되나요?**
A: 아니요. 과거 데이터 분석 전용입니다.

**Q2: 무료인가요?**
A: 네, 프로그램은 무료입니다. (키움 계좌 필요)

**Q3: 데이터 수집이 왜 오래 걸려요?**
A: 키움 API 초당 5건 제한 (2,500개 종목 = 며칠)

**Q4: 백테스팅 수익률이 좋으면 실제로도 벌 수 있나요?**
A: 과거 성과 ≠ 미래 수익. 참고용으로만 사용하세요.

## 문제 해결

### "No module named 'sqlalchemy'"
```powershell
pip install -r requirements.txt
```

### "32비트 Python을 찾을 수 없습니다"
1. Python 3.12 (32비트) 다운로드
2. C:\Python312-32에 설치

### "데이터베이스 연결 실패"
1. PostgreSQL 실행 확인
2. .env 파일 확인
3. 데이터베이스 생성: `CREATE DATABASE trading_db;`

### GUI 창이 안 뜸
```powershell
taskkill /F /IM python.exe
python gui_main.py
```
