## 1. Executive Summary

### 1.1 Phase 2 비전

키움 API만으로는 **국내주식 + 과거 시세**만 가능합니다. Phase 2에서는:

- **KIS API**: 해외주식(미국, 중국, 일본) + OAuth 인증
- **DART API**: 재무제표 + 기업정보 + 공시 데이터
- **UnifiedAPIClient**: 3개 API 통합 인터페이스

를 추가하여 **글로벌 백테스팅 + 펀더멘털 분석** 능력을 확보합니다.

### 1.2 Phase 1 대비 변화

| 항목 | Phase 1 | Phase 2 |
|------|---------|---------|
| **데이터 소스** | 키움 1개 | 키움 + KIS + DART (3개) |
| **지원 시장** | 국내주식 | 국내 + 해외(미국, 중국, 일본) |
| **데이터 종류** | 시세 | 시세 + 재무제표 + 공시 |
| **인증 방식** | 키움 로그인 | OAuth 2.0 + API Key |
| **DB 테이블** | 7개 | 7개 → 13개 (6개 추가) |
| **Pydantic 스키마** | 7개 | 7개 → 13개 (6개 추가) |
| **테스트** | 186개 | 186개 → 350개 (164개 추가) |

### 1.3 핵심 성공 지표

- **KIS API**: OAuth 인증 + 국내/해외 주식 조회 완료
- **DART API**: 재무제표 3년치 조회 완료
- **통합 클라이언트**: 단일 인터페이스로 3개 API 호출 가능
- **테스트 커버리지**: 80% 이상 유지
- **TDD 방식**: 100% 준수
